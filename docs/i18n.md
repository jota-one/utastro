# i18n setup (i36n)

## Package

`@jota-one/i36n` — configured in `src/i18n.ts`, initialized via `src/pages/_app.ts`.

## Supported languages

| Code | lang_id (DB) |
| ---- | ------------ |
| `fr` | 1            |
| `de` | 2            |
| `en` | 3            |

Default: `fr`. Detection order: localStorage → browser language → `fr`.

Storage key: `ut_lang` (localStorage).

## Translation files

Located in `src/translations/{fr,de,en}.json`. Generated from `src/sql_import_sources/hypercontent__labels.json`.

Keys use the **original underscore format** from the DB — no dot notation: `common_login`, `login_invalid_credentials`, `login_action_signup`, etc.

To regenerate the files from the JSON export:

```python
import json

with open('src/sql_import_sources/hypercontent__labels.json') as f:
    raw = json.load(f)

data = next(item['data'] for item in raw if item.get('type') == 'table')
langs = {'1': 'fr', '2': 'de', '3': 'en'}
result = {lang: {} for lang in langs.values()}

for row in data:
    lang = langs.get(row['lang_id'])
    if lang:
        result[lang][row['label_key']] = row['label_value']

for lang, translations in result.items():
    with open(f'src/translations/{lang}.json', 'w', encoding='utf-8') as f:
        json.dump(dict(sorted(translations.items())), f, ensure_ascii=False, indent=2)
```

## Usage in Vue components

```ts
import { useI36n } from '@jota-one/i36n'

const { t } = useI36n()
// t is a plain function, not a ref/computed
t('common_login')
t('common_load_more_button', { size: 10 })
```

## Astro components

i36n is Vue-only (client-side). **Not available in `.astro` files.** For multilingual content in Astro components, use a `lang` prop and conditional rendering or a plain object lookup:

```astro
---
const { lang } = Astro.props
const labels = { fr: 'Contactez-nous!', de: 'Kontakt', en: 'Contact' }
---
<h1>{labels[lang]}</h1>
```
