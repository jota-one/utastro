# ut-astro

## Context

Migration of the `urban-training` Nuxt + Node + MariaDB app to Astro + PocketBase.
The deliverable must match the original as closely as possible unless explicitly told otherwise.

**When implementing or migrating a component, always look for the equivalent in the `urban-training` sibling project first. If the sibling project is not found at the expected relative path, ask the developer to provide its location before proceeding.**
